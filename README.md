# 에코 스파이 🌍🕵️ — 12단원 We Should Save the World

캐릭터가 맵을 직접 걸어 다니며 영어 문제로 시설을 복구하고, 몰래 숨은 환경 파괴범을 찾는 추리 게임입니다.

- 학생 주소: `https://(배포 주소)/?code=반번호`
- 교사 주소: `https://(배포 주소)/teacher`

## 수업 진행 순서
1. 교사 주소에서 **[새 반 만들기]** → 화면의 반 번호와 학생 주소를 띄웁니다.
2. 학생들이 태블릿으로 들어와 이름을 씁니다.
3. **[자동 모둠 배정]** → 7~9명씩 나뉩니다. (인원이 애매하면 6~10명)
4. **[전체 시작]** → 모든 모둠이 한꺼번에 시작합니다.
5. 끝난 모둠은 **[다시 하기]**로 같은 친구들과 바로 다시 합니다. 점수는 판마다 쌓입니다.

## 역할 (모둠 인원에 따라 자동)
| 인원 | 환경 파괴범 | 중립 | 환경 수호자 |
|---|---|---|---|
| 7명 | 2 | 1 | 4 |
| 8명 | 2 | 1 | 5 |
| 9명 | 2 | 1 | 6 |
| 5~6명 | 1 | 1 | 나머지 |

- **환경 수호자**: 장치 앞에서 영어 문제를 맞혀 복구율 100% 만들기, 또는 파괴범을 모두 추방하기
- **환경 파괴범**: 문제를 맞혀 파괴 에너지를 모으고, 시설을 고장 내거나 친구를 얼려서 오염도 100% 만들기
- **중립** (교사가 고른 직업 중 무작위, 학생은 왼쪽 위 **[내 역할 ❓]** 버튼으로 직업 설명을 언제든 다시 봄)
  - 📰 환경 기자: 취재 시설 3곳 문제 맞히기 + (끝까지 살아남기 또는 특종 성공)
  - 🗑️ 쓰레기 괴물: 회의에서 추방당하면 승리 (게임은 계속됨)
  - 💰 환경 투자자: 코인 3개를 모은 뒤 이길 팀에 투자, 그 팀이 이기면 승리

## 승리 조건
- 수호자 팀: 복구율 100% (수호자 1명당 4문제, 교사 설정) 또는 파괴범 모두 추방
- 파괴범 팀: 오염도 100% (수리 실패 1번에 +25%) 또는 남은 인원이 파괴범 수 이하
- 시간 종료: 복구율이 오염도보다 높으면 수호자, 아니면 파괴범 승리
- 점수: 수호자 승리 +1, 파괴범·중립 승리 +2

## 회의
얼어붙은 친구를 **[신고]**하거나 본부의 **[긴급회의]** 버튼(한 판에 한 번)을 누르면 회의가 열립니다.
학생은 12단원 표현이 들어간 문장 버튼으로만 말합니다. (예: *I think ___ is a destroyer.* / *We should vote for ___.* / *Don't forget to vote!*)
처음 15초는 이야기만 하고, 그다음 투표합니다.

## 문제 바꾸기
`questions.js` 파일을 열어 고치면 됩니다. 한 문제는 이렇게 생겼어요.
```js
{ q: "We should ___ the world.", c: ["save", "saves", "to save", "saving"], a: 0 },
```
`c`는 보기 4개, `a`는 정답 번호(0부터)입니다. 보기 순서는 게임에서 섞여 나오고, 정답 자리가 연속으로 같지 않게 나옵니다.

## Render에 올리기
이 게임은 서버가 필요해서 GitHub Pages·Netlify로는 돌아가지 않습니다.
1. GitHub에 새 저장소를 만들고 이 폴더의 파일을 올립니다. (`node_modules` 폴더는 올리지 않아요)
2. Render → New → **Web Service** → 저장소 선택
3. Build Command: `npm install` / Start Command: `npm start`
4. 만들어진 주소 뒤에 `/teacher`를 붙이면 교사 화면입니다.

무료 Render는 한동안 접속이 없으면 잠들어서, 수업 시작 1~2분 전에 교사 화면을 먼저 열어 깨워 두세요.
서버가 다시 시작되면 반과 점수가 사라지니, 한 수업 안에서 쓰는 걸 기준으로 만들었습니다.

## 그래픽
모든 그림은 **상세 일러스트 원본 묶음(1~4/7)의 `00_화려한_원본_통짜시안`** 에서만 가져옵니다. 이전 패키지 그림은 쓰지 않습니다.
그림을 다시 만들 때(파이썬 Pillow·numpy·scipy 필요):
```
python3 tools/build_assets_v3.py <묶음을_푼_폴더> public/assets   # 캐릭터·버튼·카드·효과·장면
python3 tools/build_map.py       <묶음을_푼_폴더>                 # 지도에 맞춘 걷는 길(public/map.js)
```
- 지도: 상세 지도 그림을 1800×1200으로 키우고, 회색 돌길을 찾아 걷는 길을 만듦
- 캐릭터: 새싹 크루 시트의 9색 + 같은 그림의 색만 바꾼 3색(하늘·흰·연두), 걷기 10프레임·얼음·유령·신고 모습
- 행동 버튼·역할 카드·배지·지도 마커: 역할 UI 시트 한 장에서 모두 가져와 모양을 통일
- 투표 카드, 회의 버튼·게이지(반짝이 아이콘 세트), 시설 4가지 상태 그림, 정답·오답 배지, 효과 프레임, 회의·투표 결과·승리 장면
- 글꼴: Jua(OFL 라이선스) — `public/fonts/jua/`
